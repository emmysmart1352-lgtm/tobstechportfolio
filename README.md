# Tob’s Tech website

Static site, no build step. Pages are routes inside `index.html` (`#services`, `#service-web`, `#service-shopify`, `#service-marketing`, `#service-security`, `#service-creative`, `#work`, `#about`, `#contact`).

## Deploy
- **Vercel:** import this GitHub repo, framework preset "Other", no build command.
- **GitHub Pages:** Settings > Pages > Deploy from branch > `main` / root.

## Edit
- Colors: the `:root` block at the top of `index.html` (`--a`, `--b`, `--bg`).
- Case-study numbers: replace the placeholder results in the Portfolio section with verified client results.
- Photo: `assets/toby.jpg`. Favicon: `favicon.ico` and the PNG icons.
